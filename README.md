<h2> 📌 Project Overview </h2>

**Aurum Equities** is a web-based platform that allows users to explore, compare and simulate investments in publicly traded gold equities.

The platform focuses on three investment categories:

<table>
  <tr>
    <td align="center">⛏️<br><b>Senior Gold Miners</b></td>
    <td align="center">💰<br><b>Royalty & Streaming</b></td>
    <td align="center">📈<br><b>Gold ETFs</b></td>
  </tr>
</table>

<h2> ✨ Key Features </h2>

- **Gold Stock Screener** – Filter and explore gold-related companies by business category.
- **Financial Metrics** – Compare stock prices, All-In Sustaining Cost (AISC), dividend yields and one-year performance trends.
- **Trade Simulator** – Select equities and preview simulated investment positions.
- **Investment Insights** – Explore different gold investment business models.

<h2> ☁️ Development Journey </h2>

Developed during the **Vibing Lounge at Google DevFest KL 2026**, on 14 December 2026.

This project explored how AI-assisted development can accelerate the journey from an initial idea to a publicly accessible cloud application.

<b>Development Highlights:</b>

1. 💡 Conceptualised the gold equity screening platform.
2. 🤖 Used Google Antigravity for AI-assisted application development.
3. ☁️ Utilised approximately **US$5 in Google Cloud credits**.
4. 🚀 Deployed the application using Google Cloud Run.
5. 🌐 Published the platform for public access.

<h2> 🎯 Key Learning Outcomes </h2>

- Generative AI and AI-assisted software development.
- Rapid application prototyping.
- Financial data visualisation.
- Google Cloud infrastructure and deployment.
- End-to-end application development.
